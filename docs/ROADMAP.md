# Roadmap

Cada GOAL tem escopo próprio. Requisitos, dados e critérios de aceite de etapas futuras devem ser definidos antes de sua implementação.

## GOAL 00 — Fundação do projeto

- [x] Registrar regras permanentes e documentação inicial.
- [x] Preparar a estrutura inicial sem recursos comerciais.

## GOAL 01 — Homepage demonstrativa

- [x] Criar a homepage original com navegação, veículos demonstrativos, diferenciais, apresentação institucional e rodapé.
- [x] Preservar o conteúdo original durante a migração.

## GOAL 01.1 — Migração Astro e identidade visual

- [x] Migrar a homepage para Astro com TypeScript strict e saída estática.
- [x] Extrair layout, componentes, tipos, conteúdo e comportamento para `src/`.
- [x] Passar `npm run check` e `npm run build`.
- [x] Preparar e revisar três propostas visuais completas, com capturas desktop e mobile.
- [ ] Aguardar a escolha da direção visual pela usuária.
- [ ] Aplicar a direção escolhida ao site Astro, finalizar os tokens de `docs/DESIGN_SYSTEM.md` e validar novamente.

## Etapas futuras — a definir

1. Levantar requisitos do catálogo público e definir conteúdo e dados necessários.
2. Detalhar a experiência e os canais para negociação.
3. Definir requisitos, perfis e controles do painel administrativo.
4. Especificar uma eventual API e banco de dados antes de implementar backend.
5. Planejar validação, segurança, acessibilidade e publicação conforme o escopo aprovado.

GOAL 02 e as etapas seguintes não estão iniciadas nem autorizadas por este roteiro.
