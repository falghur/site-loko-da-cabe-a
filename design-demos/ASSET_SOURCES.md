# Fontes de imagens dos protótipos

As fotos nesta pasta aparecem apenas como atmosfera visual. Elas não representam os três veículos demonstrativos, estoque, estado, preço ou parceria da Prime Motors.

Os JPEG originais foram preservados. Os protótipos carregam derivados WebP em qualidade 82; a foto urbana foi reduzida para 1440 × 1920 px. Somadas, as três versões carregadas caíram de 797.047 bytes para 447.816 bytes (44% a menos).

Pexels informa que suas fotos podem ser usadas gratuitamente e que atribuição não é obrigatória; os créditos abaixo são mantidos para rastreabilidade. Verifique a [licença Pexels](https://www.pexels.com/license/) antes de reutilizar as imagens fora destes protótipos.
